Linker Partition Planner

Flash region

Values: 0x8000, 32768, 32K, 1M, 1.5K. K/M are ×1024.

RAM (used in every .ld file)

Reserved RAM becomes a separate RAM_NOINIT region at the top, e.g. for flags shared between bootloader and application.

Partitions

Leave Offset empty to place a partition right after the previous one. Offsets are relative to the start of the region (or bank). “Fill” takes all remaining space (last partition only).

Memory map

Drag a block’s right edge to resize (snaps to the page size), drag a block sideways to reorder. Keyboard: focus a handle and use ←/→ (Shift = ×10 pages); focus a block and use Alt+←/→ to reorder. Reordering re-packs the partitions and clears fixed offsets.
